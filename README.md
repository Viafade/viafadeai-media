# viafadeai-media

Dauerhaftes Hosting für Viafade / AI-Tech & Money Shorts (Jacob).

## Struktur

- **`masters/<projekt-slug>/`** — Metadaten jedes fertigen Masters: `CHECKSUMS.txt`, Cover, SRT, `RELEASE.md` (Link zum Release).
- **GitHub Releases** — die großen MP4s (Tag = Projekt-Slug), z. B. [finance-gta6-ttwo-v2](https://github.com/Viafade/viafadeai-media/releases/tag/finance-gta6-ttwo-v2).

Neue fertige Master: Release hochladen **und** Ordner unter `masters/<slug>/` committen.
